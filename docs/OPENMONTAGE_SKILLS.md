# OpenMontage skills

Upstream skills, stage directors and tool skills stay in the pinned checkout on the studio worker (`skills/`, `.agents/skills/`). Installing a new upstream skill means moving the pin after a compatibility test, which is a deploy.

A recipe uploaded in AI Studio → Skills is the Cinema Skill JSON schema. `SKILL.md` is compiled from its fenced JSON. No language model is configured, so the page says the draft came from the file. The draft is not activated and is not executed. JavaScript, Python, shell, FFmpeg fragments and remote URLs are rejected by the existing validator.

Uploaded ZIP plugins are not accepted on this route.
